# Report to the Barangay: install steps
1. Copy every file in this zip over your project in C:\xampp\htdocs\barangay-landayan (same folders).
2. phpMyAdmin > Import > choose database-reports.sql (adds the reports and report_images tables).
3. Press Ctrl+F5 in the browser to reload the new CSS and JS.
4. Open http://localhost/barangay-landayan/report.php

Camera capture on a phone needs the site opened from the phone. On localhost use your PC's IP (http://192.168.x.x/barangay-landayan/report.php).
Note: some phones only allow the camera on HTTPS, but the file picker fallback always works.
